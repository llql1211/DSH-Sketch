# DSH-Sketch（fork）说明

本仓库是 [QinLuza/dsh-aisketch](https://github.com/QinLuza/dsh-aisketch)（MIT © QinLuza）的 fork，由 llql1211 维护。上游提供「模型只给结构、客户端负责作图」的卡片通道；本 fork 保留这一核心，按自己的使用习惯做了若干整体调整。

## 基线与版本

- 上游基线：当前为 **v0.3.0**（commit `370936c`）。本 fork 按独立演进维护，版本与上游解耦；合并上游改动时更新基线，并写进版本标签的 `+upstream.X.Y.Z`。
- 版本标签：采用 `v<A.B.C>+upstream.<X.Y.Z>`，当前为 `v0.4.0+upstream.0.3.0`（A.B.C 为本 fork 独立版本，X.Y.Z 为上游基线）。`+upstream.X.Y.Z` 是构建元数据，不参与版本优先级比较；旧 tag `v0.3.0+fork.1` 保留原样，自切换点起用新号，不改写、不重命名。
- 逐版更新记录见 `docs/FORK_CHANGELOG.md`，在准备发布新版本时编写。

## 与上游的整体差异

1. **依赖与兼容性**：对齐 DSH 0.2.2 的 engines 与依赖声明，移除 bundle 对 DSH 自带 cordis 的依赖声明；工具测试迁移到 DSH 0.2 的批处理 API。
2. **正文围栏渲染**：图卡与函数图在回答正文的 `aisketch` / `aisketch-plot` 围栏内就地渲染，绘图提示词随之切到围栏格式；`show_card` 结果回显 `ref`，正文用 `{"ref":...}` 复用同一份规格，避免重复生成 JSON。
3. **表格策略（fork-only）**：表格回归正文 Markdown，`show_card` 不再接受 `table`。这是本 fork 的产品取舍，不跟随上游。
4. **图示能力**：流程图支持 `TB` / `LR` 方向并在卡片内居中；曲线对比按全部曲线拟合 y 轴、在定义域端点精确补点；函数图可开启坐标轴等比显示；围栏里的工具参数别名统一归一化。
5. **图片交互**：图表卡片可一键保存 PNG；插图按比例居中，不再撑满会话栏；draw 插图改用带 PNG data URL 的 `<img>`，右键即可复制图片；figure / flowchart 与函数图可通过卡片按钮把当前画面写入剪贴板。
6. **主题与预览**：图表配色与卡片文字适配 DSH 明暗主题，避免暗色文字发黑与字体回退；预览说明中标注文字方块是宿主无字体栅格化下的占位符。

## 边界与维护方式

- 上表第 3 项、本仓库的元数据（包名、仓库地址、版本标签）以及本文档属于 fork-only；上游原有的文档与发布资产保持原样。
- 其余改动与上游方向一致；上游若独立实现同类能力，本 fork 在换基线时通过 rebase 消化冲突，不长期保留重复机制。
